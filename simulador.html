El Proceso de Ingeniería y la Solución de Problemas

Comprender el proceso de ingeniería para resolver problemas de manera creativa, lógica y eficiente, considerando necesidades reales, restricciones y recursos disponibles. "La ingeniería no solo construye cosas, construye mejores oportunidades."

Clase 1

Planteamiento del Problema

Observar la realidad, analizar contexto y definir objetivos.

Clase 2

Proceso de Diseño

Investigar, generar ideas (lluvia de ideas), bocetos y prototipos.

Clase 3

Requisitos y Restricciones

Condiciones que debe cumplir, límites (costo, tiempo, ambiente).

Clase 4

Prototipo y Experimentación

Construir versión inicial, realizar pruebas y hacer ajustes.

Clase 5

Evaluación, Mejora e Innovación

Analizar funcionalidad, costo, impacto ambiental y satisfacción.

Framework de Prompting

Anatomía de un Prompt para Simulación de Ingeniería

Para obtener resultados confiables al simular proyectos técnicos en preparatoria, integra estos 5 elementos:

1. ROL

Perspectiva

Asigna la experiencia a la IA (ej. "Actúa como ingeniero experto en sistemas hidráulicos...").

2. TAREA

Objetivo Directo

La acción clara que debe realizar (ej. "Diseña un protocolo de pruebas...").

3. CONTEXTO

Marco del Trabajo

Detalles de nivel preparatoria, limitaciones del proyecto o lugar de aplicación.

4. FORMATO

Estructura Salida

Indica cómo quieres la respuesta (tabla comparativa, viñetas, pasos numerados).

5. RESTRICCIÓN

Límites y Ética

Instrucciones de lo que NO debe hacer (ej. "No uses fórmulas complejas de universidad").

Guía Paso a Paso

Instructivo para Crear Prompts de Simulación

Sigue este instructivo para estructurar tu orden y pruébala en el generador automático:

Paso 1: Define claramente el Rol que asumirá la IA según tu proyecto (ej. experto en ecotecnias, programador de sensores, etc.).

Paso 2: Establece el Contexto del problema real que estás resolviendo (ej. escasez de agua en una comunidad, optimización de energía escolar).

Paso 3: Redacta la Tarea principal que simulará la IA (evaluar prototipos, calcular costos, revisar impacto ambiental).

Paso 4: Selecciona el Formato de salida más útil para tu presentación o reporte escolar.

Paso 5: Agrega las Restricciones para mantener el proyecto dentro del nivel de preparatoria.

Caso Práctico • Clase 5

Evaluación y Mejora: Sistema de Captación de Agua de Lluvia

Ejemplo Integrador

🌧️ Contexto del Proyecto Integrador

Diseño de un sistema de captación de agua de lluvia para una casa (basado en la Unidad II):

  • Clase 1: Se identifica el problema (falta de agua en temporada seca).
  • Clase 2 y 3: Se investiga, se establecen requisitos y restricciones (capacidad, costo, espacio disponible, materiales).
  • Clase 4: Se construye un prototipo (sistema básico de filtrado).
  • Clase 5 (Evaluación y Mejora): Se evalúa si el sistema funciona, se mide la cantidad y calidad del agua, y se mejora agregando filtros más eficientes o conectándolo a un almacenamiento mayor.

💡 Ejemplo de Prompt Estructurado para este Caso:

"Actúa como asesor experto en ecotecnias escolares. Contexto: Estamos evaluando el prototipo de un sistema de captación de agua de lluvia para casas en temporada seca. Tu tarea es: Analizar los aspectos de funcionalidad, costo, impacto ambiental y satisfacción del usuario del prototipo básico. Entrega el resultado en una tabla de evaluación con recomendaciones de mejora. Restricciones: Mantén el lenguaje accesible para alumnos de preparatoria y no inventes normas técnicas complejas."

🎯 Aspectos Clave a Evaluar (Clase 5)

Al simular la mejora de tu proyecto en preparatoria, recuerda revisar siempre: Funcionalidad, Costo, Impacto ambiental, Satisfacción del usuario y Posibilidad de mejora o escalamiento.
